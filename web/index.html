PayStation

A parking meter built test-first in Java — this is the real Swing app, running in your browser on a WebAssembly JVM.

Booting the JVM… (first load takes a few seconds)

Try it

  1. Insert a few coins.
  2. Hit Buy Ticket for a receipt, or Cancel to get coins back.
  3. In the admin panel, Change Rate Strategy to another town and watch the price change for coins already inserted.
